# Luxury Housing Analysis

## Project Overview
This project analyzes luxury housing sales data using Python, SQL, and Power BI.

## Tools Used
- Python
- MySQL
- Power BI

## Project Pipeline
CSV Dataset
↓
Python Data Cleaning
↓
MySQL Database
↓
SQL Analysis
↓
Power BI Dashboard

## Dashboard Features
- Property Count by Micro Market
- Total Ticket Price
- Average Ticket Price by Micro Market
- Transaction Type Analysis
- Quarter-wise Sales Trend
- Interactive Slicers

## Conclusion
This dashboard provides insights into luxury housing sales trends and helps compare different micro markets.
